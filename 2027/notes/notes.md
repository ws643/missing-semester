## Linux

### 语法

  - cd  ----更改文件夹
  - cd .. -----回到上一级目录
  - pwd -----显示当前目录
  - clear -----清屏
  - ls ----显示当前路径下的所有文件
  - ls -al ----显示所有文件包括隐藏文件
  - touch ----新建文件
  - file ----显示文件类型
  - mkdir ----新建文件夹
  - rm 文件名----  删除文件
  - rm -r---- 递归删除文件夹里所有文件
  - cp 原路径 目标路径 -----复制文件到目标路径
  - cp -r 原路径 目标路径  -----复制文件夹到目标路径
  - mv 原路径 目标路径 -----复制文件到目标路径
  - find 目录 -name 名字 ----在路径下搜索文件
  - sudo ----暂时获得管理员权限
  - chmod 权限 文件名 ------如遇 [ permission denied ] 就是缺执行权限
  [+x表示加执行权限 -R递归（必须大写）]
  - cat ----打印整个文件内容到终端
  - ps ---- 查看当前进程
  - top ---查看系统资源占用
